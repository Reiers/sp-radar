Methodology

How we counted

1. Source data. Filecoin chain state via our own Lotus mainnet node JSON-RPC. Active SP set from Filfox /miner/list/power. FoC providers from on-chain ServiceProviderRegistry contract 0xf55dDbf63F1b55c3F1D4FA7e339a68AB7b64A5eB.

2. Operator deduplication. Union-find clustering on shared Owner, Worker, Control, Beneficiary addresses, plus shared IPs (with a 50-miner CDN cap to avoid false unions through Cloudflare-like proxies). Zero-power miner IDs are excluded.

3. Software detection. libp2p identify probe on each peer; agent string + protocol set classified into Curio / Boost / lotus-miner / Venus-miner / Droplet / Markets / private / no-peer-id / other.

4. Power split. QAP = raw + 9 × raw_verified, so verified-raw ≈ (QA − raw) / 9. CC = raw − verified.

5. IP geolocation. db-ip.com free GeoLite2-compatible mmdb (city + ASN, monthly snapshot).

6. FoC reachability. Live HTTP probe of each serviceURL/pdp/ping at snapshot time, with declared-vs-resolved location match.

Limitations. Operator dedup is structural-only (no manual heuristics); the previous report's tighter 73-operator number used additional naming-pattern signals not yet wired here. SP dial reachability is from a single vantage point. GeoIP reflects announced multiaddr IPs — VPN / relay endpoints can mislead.
